# AJR Dev Log v3.2

The hero gets a photo, a new name and a new look.

- Full-width hero photo with three crops (desktop, tablet, phone), so each device downloads only the one it needs
- The hero name is now "ANTHONY JOSEPH ROBLES", kept on one line on every screen
- Tagline and buttons moved below the name, with type that scales with the screen
- New heading font, Chakra Petch, for a hacker-style feel
- The glitch effect now runs on the hero background as well, in step with the name
- Page title, description and sharing tags now use Anthony Joseph Robles, with a rebuilt and smaller preview image
- Unused files removed from the repository

No third-party scripts were added and the Content Security Policy is unchanged.
